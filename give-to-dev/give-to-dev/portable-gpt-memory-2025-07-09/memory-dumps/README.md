# Memory Snapshots
This folder holds AI-state memory representations.
Each snapshot is a full dump of what DevlinGPT "knew" about a topic at a given point 

Each file will: 

- list EVERY msg including all text contextually relating to [the topic]
- date ordered so I could read through the entire conversation again even if they spanned months 
- be based on the previous log and ADDED to with all related chat msgs since the last update to date

These ARE NOT summaries, they're entire chat logs about specific topics but you should retain as much as you can when building these from raw chat logs

A single command will be used to run:

- chat logs
- memory-dumps
- abstractions
