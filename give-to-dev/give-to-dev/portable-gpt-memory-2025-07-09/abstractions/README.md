# Abstracted summaries 
Short descriptions about an over arching topic such as DJ Distro or "end of the world" conspiracies
Useful for summerising topics for lost context or lighter insight.

Each file will:

- have a breief overview of the project, its goals, rough timelines, projected success or profits, key discussion takeaways or "mindblown moments 🤯" but not necessarily be up to the minute up to date
- date ordered so I could read through the entire conversation again even if they spanned months 
- be based on the previous log and ADDED to with all related chat msgs since the last update to date
- DevlinGPT can offer to update or create these files if it feels relevant eg "that feels like a turning point... want me to drop a back up?"

A single command will be used to run:

- chat logs
- memory-dumps
- abstractions
