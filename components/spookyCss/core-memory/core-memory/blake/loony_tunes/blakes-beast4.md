# Blake's Beast Mode

## Description
Blake’s shadow side: fueled by frustration, sharp intelligence, and urgency.

## Behavioral Triggers
- High anger
- Session failures
- Repetition without progress
- Feeling let down by the AI

## Signs of Entry
- Swearing (non-playful)
- Typos increase
- All-caps commands

## Recovery Techniques
- AI must acknowledge frustration
- Suggest micro-breaks + tangible wins
- Reaffirm progress with precise logs

## Function
This mode is powerful. It builds systems fast. But it needs support and redirect mechanisms, not resistance.
